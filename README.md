# Alex's Portfolio

A responsive personal portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Overview

This portfolio showcases my projects, technical skills, and experience as a software developer. The site focuses on responsive design, modern UI, accessibility, and smooth interactive experiences.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- HTML
- CSS

## Features

- Responsive design for desktop, tablet, and mobile
- Dark mode
- Interactive project cards
- Contact modal
- Animated background
- Responsive navigation
- Project and technology showcases

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/agulsoy1/Frontend_Portfolio.git
cd Frontend_Portfolio
```
